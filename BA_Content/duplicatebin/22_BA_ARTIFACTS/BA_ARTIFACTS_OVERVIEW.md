## 2. Artifact Mapping to Delivery Lifecycle

| Lifecycle Phase | Core Artifacts | Primary Stakeholders | Governance Standard |
|---|---|---|---|
| **Initiation & Strategy** | Business Case, Project Inventory, Stakeholder Analysis | Executive Sponsor, Business Owner | PMI / BABOK v3 |
| **Requirements Discovery** | Requirements Catalog, Process Flows, Gap Analysis | Product Owner, End Users | IEEE 830 / ISO 29148 |
| **Functional Specification**| BRD, FRD, PRD, User Stories, Use Cases | Software Architects, Engineering Leads | Agile Scrum / User Stories |
| **Technical Design Bridge** | API Business Analysis, Data Dictionary, ERD | Backend & Frontend Developers | RESTful OpenAPI / UML |
| **Verification & Testing** | UAT Plan, UAT Test Cases, Traceability Matrix (RTM) | QA Engineers, Business Users | ISTQB / UAT Standards |
| **Governance & Change** | Change Request Log, Decision Log, Risk Register | Change Control Board (CCB) | ISO 31000 / ADR |
| **Audit & Interview Readiness** | Metrics Audit, Resume Claim Audit, Case Study | Interview Evaluation Panels | Empirical Fact Auditing |
